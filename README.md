# SmartInvoice

OCR intelligent et rapprochement automatique des factures fournisseurs avec Odoo.

## Technologies

- Odoo
- Python
- PaddleOCR
- OpenCV
- RapidFuzz
- PostgreSQL

## Objectif

Automatiser le traitement des factures fournisseurs :

PDF/Image

↓

OCR

↓

Extraction

↓

Matching Purchase Order

↓

Création Vendor Bill

↓

Validation
